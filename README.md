# Pre-IPO Investment Hub

An AI-powered demo platform for learning about and simulating investments in private companies.

## Demo Features
- Investment dashboard with €10,000 virtual balance
- Marketplace featuring 5 fictional private companies
- Simulated buying and selling of shares
- Virtual investment portfolio
- Transaction history
- AI-powered investment knowledge hub
- Modern responsive fintech design

## Important
This is a demonstration platform only. All companies, prices, balances and transactions are fictional. No real investments, payments, or securities transactions take place.

## Technology
Next.js, TypeScript and Tailwind CSS.
